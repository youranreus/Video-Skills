# 待生成试片包

这里包含一个虚构角色、一个控制室和两集最小制作材料；**没有生成图片、视频或声音，没有任何真实资产被验收**。

- [对白试片预览](试片/对白/预览.md)：先选声线并 TTS，再以图像＋音频参考生成 Wan 对白视频。
- [动作试片预览](试片/动作/预览.md)：首尾帧控制，独立声音后期。
- [作品目录](作品/)：EP001 右袖破损，EP002 延续；用于展示跨集状态。

## 使用顺序

1. 复制本目录到项目仓库外作为新作品；或用 `scripts/create_starter.py /新位置/作品` 重新创建。
2. 用内置图片工具制作角色身份与场景参考，导入后实际审看。制作动作首尾帧和对白画面，使用试片 JSON 中给出的目标路径导入。
3. 选择 Qwen 音色，先在配音单登记独立试听行，使用临时候选声线试音任务（参考项目契约中的试听流程）；试听认可后将音频及音色 ID 收入角色采用版本。
4. 当前 v001 都是候选。通过 add-version 建立完成的 v002，更新两集视觉设定、配音单、视频输入契约及任务 JSON 的资产引用。不要修改已封存的 v001。
5. 配置 short-drama.json 的 production.workspace_id 与同地域连接，凭据使用 DASHSCOPE_API_KEY 环境变量。
6. 对 tts-job.json 执行 prepare，在明确授权后 confirm/run；回听并 accept-media。把实际音频与时长回填配音单，在对白分镜加 dialogue_audio；若台词放不下，先修改镜长。
7. check 通过后对 video-job.json prepare。按预览授权并生成，再审看、记录案例；没有新增授权不做质量重试。

示例中初始 check/prepare **应被候选资产和缺媒体拦截**。这证明待补资料不会被当作投产完成；不属于验收失败或已产生供应商错误。
