## 复现

```bash
python3 -m unittest discover -s tests -v
python3 scripts/validate_skills.py
```

混音测试需要 `VIDEO_SKILLS_TEST_FFMPEG` 指向 ffmpeg；未提供时只跳过该渲染用例。本轮使用临时虚拟环境中的 imageio-ffmpeg 运行，没有安装到全局。官方技能校验使用临时环境的 PyYAML。
