# video-motion

首尾帧、首帧、多模态参考分别绑定真实类型。视频提示词.md 的 video-inputs 块按 MOTION ID 保存输入媒体、资产版本与镜长，正文保留可复制提示词。首尾帧不可混入音频。音色参考与准确音轨复用分开；尚无真实音频时使用待补计划，不提交。先测对白时长，声音与画面验收独立记录。
