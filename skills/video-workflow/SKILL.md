# 视频工作流入口

用户只需提供作品目录，例如：`$video-workflow 恢复 /我的作品，继续 EP002`。技能仓库不是作品目录；新项目才初始化，已有项目不重新初始化。

## 恢复与继续

1. 定位用户指定目录，读取其 AGENTS.md。调用已安装的 video-produce 技能目录中的 `scripts/workflow.py resume <项目绝对路径>`；指定单集时加 `--episode EP002`。这一步只读，不联网、不提交、不修改进度。
2. 根据报告读取相关来源文件，向用户简述：**当前进度、待审内容、在途/待取回任务、阻塞、下一步**。文件存在只说明有产物；没有绑定当前正文的验收依据就标“验收状态未知”，不自动重写、不补造通过记录。
3. 先处理 in_flight。recoverable 表示有供应商句柄，需要查询或 collect；不证明供应商仍运行。submission_unknown 必须核查，不能重投。查看相关任务的现有授权和输入版本；取回已有任务使用原句柄及项目外 adapter 配置，缺配置时说明具体缺口。恢复旧素材后仍标候选，输入已变化时不自动用于新镜头。
4. 执行 next_actions 所指阶段，先读已有成果再补缺口。优先尊重用户本次指定的镜头或阶段；其他剧集在途任务也要告知，但不让无关待审内容阻止独立工作。用户说“继续”时推进可逆的整理、写作、检查和提示词准备，不只报告状态后停下。
5. 未取得任务/批次生成授权时，停在实际任务预览；已有授权且请求明确继续执行时沿原授权范围处理，不重复索要确认。恢复不扩展到新质量重试。

## 阶段路由

| 工作 | 技能 |
|---|---|
| 创意、世界观、分集大纲 | video-develop |
| 正式剧本、山音诊断 | video-write |
| 身份、场景、造型与跨集状态 | video-assets |
| 参考图、关键帧与导入 | video-images |
| 分镜、动作边界与镜长 | video-storyboard |
| 声线试听、对白与测时 | video-voice |
| Wan 提示词与输入绑定 | video-motion |
| 任务预览、执行、查询与取回 | video-produce |
| 素材审看、失败案例和规则 | video-review |
| 剪辑、混音与交付 | video-edit |

## 新建与检查

初始化用 video-produce 的 workflow.py init；核对用 check；交付用 export。不要使用保留的旧 project_tool.py init/export 创建整合版作品。

报告从正式 Markdown、资产版本、媒体登记和 .short-drama 生产事务重建，不另建 progress.json。恢复报告不是新的创作真相。文稿验收可在该文稿内记录 video-review 块，绑定正文摘要；旧正文修改后该验收失效。无法读取或损坏的资料单独报告，不推断为未开始或已完成。

详见 [项目契约](references/integration.md)。
