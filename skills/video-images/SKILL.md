# video-images

先查采用的身份与造型版本、当前状态和匹配规则。资产参考提示词放资产版本目录；单集特有图片提示词放图片提示词.md，镜头关键帧放分镜.md。可用时调用环境的内置图片生成工具，按其技能要求操作；不可用时交付提示词与缺口。图片通过 import 登记，实际审看后 accept-media。工具执行前记录适用规则及保持项，不因生成成功自动采用。三视图用于角色母版；投产参考按具体用途选取。

## 共同执行契约

生成和修改前读取作品 AGENTS.md、当前资产版本和规则。创作正文与运行记录分离：Markdown 拥有创作事实，隐藏的 .short-drama 仅记录生产事务。规则命中必须写出落实方式，主观验收保持待审。

只读取当前任务需要的参考。上游参考提供技法；其中单集独占资产、固定五文档、输出仅限单集和逐步确认等旧组织约定由本整合版替代。格式与命令详见 [项目契约](references/integration.md)。
